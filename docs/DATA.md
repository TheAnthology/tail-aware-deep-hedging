# Data provenance

Heston data is generated by `sec53_theoretical.market`; no external price dataset is required.

S&P 500 observations originate from the [OpenIntro S&P500 snapshot](https://www.openintro.org/data/index.php?data=sp500_1950_2018), attributed upstream to Yahoo Finance. The [CSV](https://www.openintro.org/data/csv/sp500_1950_2018.csv) has recorded SHA256:

`71835dbbd3b35058dc673db07b6500b9146034dde765225120a203ef1b2ae667`

The release supplies acquisition/preparation code and derived experimental outcomes, not a bundled copy of the raw vendor price series. Users obtain the source separately under its applicable terms. The original paper's exact vendor file is not verified.

Preparation preserves adjusted close labels, constructs decimal log returns, selects2007-06-12 through2018-01-02 and creates300 weekly-shifted windows, each with1218 prices/1217 returns. Each30-day experiment fits on the first1187 returns and holds out the following30. Missing observations are not interpolated. The calendar-week endpoint convention is explicitly reconstructed rather than recovered from author code.

Historical P&L is a single observed underlying trajectory per contract. Conditional simulated P&L is a separate distribution under the estimated GJR-GARCH model. No historical option quote series is included.
